# MTQ-V

MTQ-V is a public technical showcase repository derived from product-development experience, but intentionally separated from private production repositories.

This repository focuses on maintainable project governance, safe AI-assisted development workflow, and public-facing documentation patterns. It does not contain production secrets, private user data, commercial logic, payment logic, internal prompts, or the commit history of the private MTQ repository.

## Purpose

- Provide a clean public surface for open-source review.
- Document safe collaboration rules for AI coding agents.
- Demonstrate non-destructive development and release-readiness practices.
- Support future Codex for Open Source application materials.

## What is included

- Public project overview.
- Security and disclosure policy.
- AI agent contribution rules.
- Architecture and release-readiness documentation.
- Environment variable example using fake values only.

## What is not included

- Production `.env` files.
- API keys or service-role credentials.
- Private database URLs.
- Real user data.
- Private prompts.
- Commercial workflows.
- Payment or entitlement logic.
- Private repository history.

## Repository status

Public documentation foundation. Production code has not been imported.
